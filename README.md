# 🚀 Momentum - Productivity Suite

A full-stack productivity application with task management, focus timer, and analytics.

## ✨ Features

- ✅ Task Management (CRUD operations)
- ⏱️ Focus Timer with Pomodoro technique
- 📊 Analytics Dashboard
- 🌱 Virtual plant that grows with focus time
- 🎵 Background music player
- 🔐 User authentication with JWT
- 📱 Responsive design

## 🛠️ Tech Stack

- **Frontend:** Next.js, React, Tailwind CSS
- **Backend:** Node.js, Express
- **Database:** PostgreSQL
- **Mobile:** Flutter (coming soon)
- **Auth:** JWT, bcrypt
